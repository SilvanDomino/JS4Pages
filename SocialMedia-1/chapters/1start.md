Deze tutorial is ter ondersteuning van het bouwen van jullie eigen social media (of nieuws) website door gebruik te maken van Javascript. We gaan hiervoor onze content (bijna) dynamisch inladen. 

{: .note }
Dynamisch wilt zeggen dat we onze data uit onze website niet hardcoded in de HTML neerzetten maar dat we deze data uit een database halen (of uit een JSON)

Een overeenkomst tussen sociale media en nieuwswebsite is dat beiden erg veel content hebben en vaak kan je lang door scrollen op 1 pagina. De posts op een social media of nieuwswebsites hebben vaak veel overeenkomsten.

* Afbeelding en/of text
* Kop
* Datum
* Bron/naam van poster



## Stap 0: Wat ga je namaken?
Ga nadenken over welke social media (of nieuws) website je gaat namaken.

Sociale Media
* Instagram
* Reddit
* Facebook
* Twitter/x

Nieuwswebsites
* NOS.nl
* ESPN.nl
* Animenewsnetwork.com


## Stap 1: Aanmaken van het project
De eerste stap die we gaan doen is het aanmaken van het project. Naast de map waarin je de kalender hebt gemaakt maak een nieuwe map met de naam 'Social Media'.
Maak hier de HTML, Javascript en de CSS in aan.

* index.html
* style.css
* main.js

## Stap 2: De basis
Maak de HTML pagina aan. Gebruik hier `!` voor. Maak ook de CSS aan, inclusief CSS reset. Hier een hele minimale CSS reset.
```css
*{
    padding: 0;
    margin: 0;
    box-sizing: border-box;
}
body{
    font-size: 1.6rem;
}
html{
    font-size: 62.5%;
}

```
